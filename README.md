# SDVParser-ReactJs

Frontend for processing game translation.

## Requirements

1. Node Version 18.20.5
2. NPM Version 10.8.2

## Installation

1. Use the package manager npm.
```bash
npm install
```
2. Run the app
```bash
npm run dev
```

## Usage

Make sure [SDVParser-API](https://github.com/dragonregure/SDVParser-API) is running on your local

To update your translated files to the latest version of the game, use the "Merge" option, follow the instructions, and proceed to translate the new files or lines from the latest version of the game.

After updating your translated files, use the "Merge Finished" option and follow the instructions to merge your newly translated file into the final result.
